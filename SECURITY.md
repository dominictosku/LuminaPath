# Security policy

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/dominictosku/LuminaPath/security/advisories/new).
If private reporting is unavailable, open an issue asking for a private contact
channel without including vulnerability details.

Include the affected version or commit, deployment details, impact and minimal
reproduction steps. Remove credentials and personal data from reports and logs.
Please allow time to investigate and prepare a fix before publishing details.

Security fixes target the current code on `main`. Older versions do not currently
have a separate security maintenance schedule. Upgrade to a release containing
the fix when one is available.
